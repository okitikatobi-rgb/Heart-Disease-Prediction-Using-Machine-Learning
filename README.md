# Heart-Disease-Prediction-Using-Machine-Learning

**Goal:** This project aims to develop a predictive model that accurately identifies the likelihood of heart disease in patients. By leveraging clinical data, the model supports early detection, assists medical professionals in diagnosis, and contributes to improved patient outcomes and preventive healthcare strategies.

**Project Description:** In this project, I analysed the UCI Cleveland Heart Disease dataset, which contains key clinical attributes such as age, sex, chest pain type (cp), resting blood pressure (trestbps), cholesterol levels (chol), maximum heart rate achieved (thalach), exercise-induced angina, ST depression, thalassemia (thal), and other important indicators. The project followed a complete end-to-end machine learning pipeline: Thorough data cleaning (handling missing values and duplicates)
Extensive Exploratory Data Analysis (EDA) with insightful visualisations

**Feature engineering and data preprocessing**
Training and evaluation of four different machine learning models: Logistic Regression
Random Forest
Support Vector Machine (SVM)
XGBoost

The target variable is binary:
1 = Heart disease present (High risk)
0 = No heart disease. Skills Demonstrated: Data Handling & Preprocessing  
Exploratory Data Analysis (EDA)  

**Data Visualisation**  
Machine Learning Model Development & Comparison  
Model Evaluation & Interpretation  
Healthcare Analytics & Domain Knowledge  
Problem-Solving and Analytical Thinking

**Technologies Used:** Programming Language: Python  
Data Analysis: Pandas, NumPy  
Visualisation: Seaborn, Matplotlib  
Machine Learning: Scikit-learn, XGBoost

**Key Results:** Support Vector Machine (SVM) achieved the best overall performance with 81.32% Accuracy and 83.81% F1-Score. Chest pain type (`cp`), maximum heart rate (`thalach`), and ST depression (`oldpeak`) are among the strongest predictors. Males have a higher prevalence of heart disease in this dataset.
